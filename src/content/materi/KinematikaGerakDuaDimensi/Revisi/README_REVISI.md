# Fisika Alfazrian — Revisi Chapter Kinematika: Gerak Dua Dimensi

15 file JavaScript direvisi agar lebih konsisten dengan konsep Fisika Alfazrian:
- Hook dan rasa ingin tahu sebelum definisi.
- Visualisasi sebelum rumus.
- Pola analisis: Amati → Identifikasi → Visualisasi → Analisis → Rumus → Kesimpulan.
- Bahasa ringan dan mentor-like.
- Model ideal dan asumsi fisika dijelaskan.
- Akira diposisikan sebagai karakter utama chapter Gerak Dua Dimensi ketika visual karakter digunakan.
- MiniProjectGerakDuaDimensi.js dialihkan menjadi Eksplorasi Fenomena, bukan proyek/praktikum.
- Chapter Closing diarahkan secara konseptual dari “bagaimana benda bergerak?” menuju “mengapa gerak berubah?” pada Dinamika.
